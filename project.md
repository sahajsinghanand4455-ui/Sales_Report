# 📊 Sales Performance & Revenue Analytics Dashboard

An interactive, executive-level sales performance dashboard built in Microsoft Excel using advanced Pivot Tables, Pivot Charts, KPI cards, and dynamic visual layouts to analyze regional sales, monthly trends, and product performance.

## 🚀 Project Overview
This project showcases an end-to-end data analytics workflow—structured from raw transaction records to aggregated Pivot analysis and an interactive visual dashboard designed for quick business insights.
- deshboard <a href="https://github.com/sahajsinghanand4455-ui/Sales_Report/blob/main/Screenshot%202026-11-01%20195437.png">deshboard veiw </a>
## 🛠️ Key Features & Architecture
1. **Data Structuring & Cleaning:** Organized and managed clean transactional datasets (`DATA` sheet) comprising order IDs, dates, customer details, regions, items, quantities, and pricing.
2. **Pivot Table & Pivot Analysis:** Built robust backend Pivot Tables (`PIVOT_TABLE` sheet) to dynamically aggregate metrics such as Total Revenue by Region, Monthly Sales Trends, and Product-wise Quantities sold.
3. **Interactive Executive Dashboard (`DESHBOARD`):**
   * **KPI Cards:** Real-time tracking for Total Revenue ($10.3M+) and Total Quantity sold (6,600+ units).
   * **Dynamic Visualizations:** Integrated monthly trend charts, regional distribution metrics, and horizontal product performance graphs styled in a clean green corporate aesthetic.
   * **Interactive Filtering:** Configured slicers for seamless drill-down analysis across different regions and product categories.
